Privacy.

Last updated 27 July 2026

This is a one-person portfolio site, not a company. This page explains, plainly, what data it actually collects and where it goes.

Contact form

The form in the Contact section posts your name, email, and message directly to Formspree, which forwards it to me by email. Nothing from the form is stored on this site or in any database I run; Formspree is the only place it lands.

The chatbot

Messages you send the chatbot are forwarded to NVIDIA NIM for inference, so the model can generate a reply. If you attach an image, it's sent the same way.

An email notification is sent (via Web3Forms, with Formspree as a backup if that fails) only when you explicitly ask to be put in touch with me and give the bot a name and a way to reach you. If you just chat without asking to connect, no notification is sent.

Chat messages live only in the page's memory for that browser tab. Nothing is written to local storage, cookies, or any server-side database here. Refresh the page or close the tab and the conversation is gone.

GitHub activity

The contribution graph is fetched through a server-side proxy that calls GitHub's API on my behalf. It involves no data about you at all; it only reads my own public GitHub activity. Your browser caches the response locally for a few hours so the graph loads instantly on repeat visits.

Analytics

This site uses Vercel Analytics to see anonymous, aggregate page-view counts. It doesn't use cookies and doesn't track you individually across sites.

Hosting & server logs

This site is hosted on Vercel, which, like essentially any host, keeps standard server logs (including IP addresses) for operating the infrastructure. I don't access these for anything beyond that.

Questions or data requests

If you want to know what's been sent through the form or chatbot, or have any other question about this page, email atulbiju13@gmail.com.
